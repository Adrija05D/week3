# Iris Flower Clustering Project 🌸

This repository contains the coursework and **Mini Project 3** for Week 3 of the Machine Learning & AI course. The project focuses on applying Unsupervised Machine Learning techniques to the classic Iris dataset.

## 📌 Project Overview
The goal of this project is to perform clustering analysis on the Iris dataset and evaluate the results against the actual species labels. This project demonstrates skills in data visualization, dimensionality reduction, and unsupervised learning.

## 📊 Dataset
The project utilizes the **Iris Dataset**, which contains measurements for 150 iris flowers from three different species.
*   **Features:** Sepal Length, Sepal Width, Petal Length, Petal Width.
*   **Target:** Species (Setosa, Versicolor, Virginica).

*Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/iris) / [Kaggle](https://www.kaggle.com/datasets/uciml/iris)*

## 🛠️ Tasks & Assignments

### Part 1: Assignments
1.  **K-Means Clustering:** Perform K-Means algorithm on the Iris dataset and visualize the resulting clusters.
2.  **Dimensionality Reduction:** Apply Principal Component Analysis (PCA) to reduce the dataset dimensions for efficient visualization.

### Part 2: Mini Project (Iris Flower Clustering)
1.  **Apply K-Means:** Implement K-Means clustering with `k=3` (since there are 3 species of Iris).
2.  **Visualization:** Create scatter plots to visualize the clusters formed by the algorithm.
3.  **Evaluation:** Compare the *predicted clusters* generated by the model against the *true labels* (ground truth) of the dataset to assess clustering performance.

## 🚀 Skills Gained
*   **Unsupervised Machine Learning:** Implementing clustering algorithms without predefined labels.
*   **Data Visualization:** Using scatter plots and PCA to interpret complex data.
*   **Model Evaluation:** Understanding how to compare unsupervised results with supervised ground truth.
